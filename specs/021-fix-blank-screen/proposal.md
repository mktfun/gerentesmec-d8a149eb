# Causa Raiz da Tela Branca (Supabase Client Issue)

## Overview
A aplicação reagiu com tela branca ("White Screen of Death") após a conclusão do deploy da nuvem para o Self-Hosted na VPS. 

A inspeção identificou a causa exata: a integração com o Supabase fornecida pela Lovable gerencia as chaves de forma **hardcoded** dentro do arquivo do cliente (em vez de usar variáveis globais seguras `import.meta.env`).

## Scope & Boundaries
- Refatorar `src/integrations/supabase/client.ts` para quebrar a restrição imposta pela plataforma de design e torná-lo dinâmico.
- Garantir que a build da interface seja fluida sem que o cliente perca referência do Host e API Key corretos.

## Constraints
- Como a Lovable diz `// This file is automatically generated`, modificá-lo localmente pode ser sobrescrito pelo editor visual se ele for sincronizado novamente.
- **Defesa Adotada:** Faremos a mutação no arquivo de inicialização para injetar as credenciais da Self-Hosted via `.env` ou, se quisermos ignorar o `.env` (que removemos do Git por proteção do Push), usaríamos valores fallback injetados por Build Time. Porém a forma mais segura para React Vite é chamar `import.meta.env.VITE_SUPABASE_URL`. O usuário pode colocar as "Secrets" diretamente dentro do dashboard do Lovable (Configurações do Projeto > Environment Variables) para que o Cloud Build deles receba a injeção.
